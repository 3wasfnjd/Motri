# موتري على Meta Quest

افتح رابط اللعبة بـ HTTPS في متصفح Meta Quest. تظهر أيقونة «واقع افتراضي»
في يسار شاشة التحميل، وتتفعّل بعد اكتمال تحميل العالم. اضغطها واسمح بالدخول.
يمكن استخدامها مجددًا بعد الخروج، دون إعادة تحميل اللعبة.

## التحكم

| أداة التحكم | الوظيفة |
| --- | --- |
| العصا اليسرى | توجيه السيارة |
| الزناد الأيمن | بنزين تدريجي |
| الزناد الأيسر | فرامل ثم رجوع للخلف |
| القبضة اليسرى | فرامل يد |
| A | التفاعل مع العنصر القريب |
| B باستمرار | التسارع الإضافي |
| القبضة اليمنى | القفز بالتعليق |
| ضغط العصا اليسرى | بوق |
| ضغط العصا اليمنى | إعادة السيارة عند التعثر |
| X | تبديل المنظور القريب فوق السيارة / خلف السيارة |
| Y ضغطة قصيرة | إعادة توسيط موضع الرأس واتجاه النظر |
| Y لمدة 1.2 ثانية | الخروج إلى نافذة المتصفح |

المنظور القريب فوق السيارة؛ لا توجد مقصورة داخلية مصممة في الموديلات الحالية.
تبقى الكاميرا أفقية عند انقلاب السيارة. يمكن النظر والتحرك بالرأس بصورة مستقلة.
بعد الدخول أو استئناف الجلسة، أرخِ الأزرار مرة واحدة لتفعيل القيادة.

القوائم والنماذج النصية تُفتح في نافذة متصفح Quest وتُنهي جلسة VR، ثم يمكن
العودة بأيقونة VR. عالم القيادة والتحكم والتفاعلات القريبة يعمل داخل النظارة.
اختيار غرفة اللعب الجماعي والسيارة متاحان قبل الدخول؛ الاتصال الحالي يُحافظ عليه.

## التنفيذ والتحقق

- يستخدم `isSessionSupported('immersive-vr')`، وليس اسم المتصفح، لاختيار WebGL2؛
  إصدار Three.js المثبت 0.183.2 لا يدعم XR على WebGPU backend.
- `?vr=1` يتيح فحص مسار WebGL2 على الكمبيوتر دون بدء جلسة أو ادعاء وجود نظارة.
- تتوقف معالجة DOF/bloom وتغيير دقة النافذة أثناء XR، مع دقة إطار 0.8 وfoveation 1.
- تتبع الرأس يستخدم reference space من نوع `local` مع معايرة الجلسة الأولى؛
  لا يتطلب الوقوف ولا يصطنع طولًا للمستخدم.
- تحكم Quest يُقرأ من `XRSession.inputSources` حسب اليد و`xr-standard`.
- الفحوص الآلية: `node --test scripts/test-vr.mjs` ثم `npm run build`.
- يلزم تحقق فعلي على Quest من جودة الصورة ومعدل الإطارات وراحة القيادة؛
  اختبارات المحاكاة لا تقيس هذه الأمور.

### فحص النظارة

1. الدخول من شاشة التحميل والسماح بالجلسة؛ ظهور العالم في العينين.
2. تحريك الرأس بكل الاتجاهات، وتجربة البنزين والتوجيه والرجوع والقفز.
3. تبديل المنظور وتوسيط النظر جالسًا، ثم انقلاب السيارة وإعادة موضعها.
4. فتح قائمة من تفاعل، والعودة إلى VR بعد إغلاقها.
5. رفع النظارة/فتح قائمة النظام أثناء البنزين؛ التأكد من تحرير التحكم.
6. الخروج وإعادة الدخول، ثم اختبار غرفة واحدة مع لاعب من الجوال.
