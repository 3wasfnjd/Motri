# Project game cards

Three generated 16:9 billboards replace the four personal gallery images.
Runtime WebP files are 960 × 540; the gallery loads the current image and its next neighbour.
Each board has its own direct play URL; the existing link panel and mobile Open button are enabled.

Generated with the built-in image generation tool using the corresponding game repository artwork as references. These are promotional illustrations, not gameplay screenshots.
