# موتري — Motri

## فكرة المستودع
عالم قيادة واستكشاف وتحديات ثلاثي الأبعاد بهوية عبودين، يعمل من المتصفح ويتيح التجول بالسيارة والتفاعل مع المكان.

## الخدمات والمزايا
- قيادة حرة واستكشاف الطرق والاستراحة والكثبان والمناطق التفاعلية.
- طقس متغير ودورة نهار وليل وموسيقى ومؤثرات صوتية.
- واجهة عربية وتحكم باللمس مع زر مستقل لتعزيز السرعة.
