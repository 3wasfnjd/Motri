# استراحة Motri2 — نموذج خارجي خفيف

إعادة بناء أصلية من الصور الجوية الخمس والفيديو المرفق، وفق المخطط الذي راجعه المستخدم. تشمل المباني البيضاء والسور والبوابة المفتوحة والخيمة والمظلة والأحواض والممرات والتشجير المبسط. لا توجد سيارات أو أشخاص أو غرف داخلية.

## الحجم والأداء

- 10,636 مثلثًا، و17 جزء رسم، و5 خامات مشتركة.
- حجم GLB: ‏968,940 بايت، نحو 0.97 ميجابايت.
- صورة واحدة مدمجة بحجم 512 × 512 للممرات الحجرية.
- زجاج معتم ملوّن ونباتات صلبة؛ لا توجد شفافية أو زجاج انكساري أو بطاقات أوراق شفافة.
- ملف GLB مستقل، دون روابط خامات خارجية أو حاجـة إلى Draco/KTX2.
- لم يُجر اختبار أداء فعلي داخل Motri2 أو على هاتف. كلفة الظلال والإضاءة تعتمد على إعدادات اللعبة.

## المقياس والمحاور

| الخاصية | القيمة داخل الموديل |
|---|---|
| الوحدة | متر |
| أبعاد الموقع داخل المخطط | نحو 40 × 48.8 متر، تقديرية وليست قياسات للموقع الحقيقي |
| الامتداد الأمامي خارج البوابة | 6.4 متر |
| أصل النموذج | مركز البوابة عند الأرض |
| الأعلى في GLB / Three.js | +Y |
| اتجاه دخول الاستراحة | +Z |
| الأرض | Y = 0 |
| نقطة بدء مقترحة للسيارة | (0, 0, -5.5)، ثم يضيف نظام الفيزياء ارتفاع السيارة |
| فتحة البوابة الإنشائية | 5.2 متر؛ الخلوص بين تفاصيل الضلف المفتوحة يقارب 5.05 متر |

كل الأبعاد والحدود تقديرية. الواجهات المحجوبة وبصمة المبنى الصغير يمين المدخل مبسطة. الأسماء وصفية، ولا تفترض وظيفة الغرف.

## الدخول والتجول

البوابة مفتوحة للخارج بزاوية 110 درجات لكل ضلفة. السطح متصل من المدخل إلى الممر الرئيسي والساحة الترابية الخلفية. القوس الصغير بجوار التراس ممر مشاة؛ طريق السيارة يمر من الساحة إلى يساره.

المباني كتل خارجية مغلقة، والأحواض والجدران عوائق. الممر المنحني بين الأحواض جزء من الحديقة؛ المسار المقترح للسيارة يلتف حولها. الزيادات المرئية لرصف الأرض 12–21 مم، ويمكن تمثيل الأرض المستوية في الفيزياء عند Y = 0.

ملف GLB يعرض المجسم فقط. لكي تمنع السيارة من اختراق الجدران، يجب إنشاء أجسام ثابتة في نظام تصادم Motri2. ملف `collision_and_placement.json` يتضمن صناديق وأسطوانات مبسطة مستقلة عن محرك الفيزياء. التعريفات كذلك محفوظة في خصائص `RestHouse_Root` داخل GLB.

`suggested_route_glTF` يوضح ممرًا جرى فحص خلوصه بغلاف سيارة 5.2 × 2.24 × 2.05 متر. هو مثال لمساحة المرور، وليس حركة قيادة جاهزة أو مسار ذكاء اصطناعي يضمن نصف قطر دوران سيارة معينة.

## استخدام مساعد Three.js

```js
import {GLTFLoader} from 'three/addons/loaders/GLTFLoader.js';
import {configureRestHouse} from './motri2_rest_house.js';

const gltf = await new GLTFLoader().loadAsync('./RestHouse_Motri2.glb');
scene.add(gltf.scene);
const rest = configureRestHouse(gltf.scene, {
  position: [0, 0, 0], yaw: 0, scale: 1, shadows: false
});
const spawnAtGround = rest.getSpawn();
const staticShapes = rest.getColliders();
const groundAreas = rest.getGroundAreas();
// اربط staticShapes وgroundAreas بمحرك التصادم الموجود في اللعبة.
```

المساعد يحوّل مواضع التصادم إلى إحداثيات العالم بعد النقل والدوران والتحجيم الموحد. لا ينشئ محرك فيزياء ولا يغير قيادة السيارة. فعّل الظلال فقط إذا كانت ميزانية أداء اللعبة تسمح بها. النموذج يحتاج إلى إضاءة اللعبة؛ إضاءة صور المعاينة لا تدخل في GLB.

## التنظيم والتعديل

الجذر `RestHouse_Root`. الأجزاء مجمعة حسب الخامة والدور لتقليل طلبات الرسم: `RH_Walls`, `RH_Roofs`, `RH_Ground`, `RH_Paving`, `RH_Tent`, `RH_Basins`, `RH_Foliage` وغيرها. الضلفتان منفصلتان: `RH_Gate_Left`, `RH_Gate_Right`، ولكل واحدة محور مفصلة.

ملف Blender قابل للتعديل. ملفات Python المرفقة توثق البناء والتحقق. لإعادة البناء داخل Blender: شغّل `build_rest_house.py`، ثم `align_reference.py` لضبط يمين ويسار المخطط، ثم `render_previews.py` عند الحاجة للمعاينات، ثم `fix_and_finalize.py` قبل التصدير. الإحداثيات داخل Blender تستخدم +Z للأعلى و-Y إلى داخل الموقع.

## الفحوص

راجع `blender_validation.json` لفحص الخلوص والهندسة، و`gltf_validation.json` لفحص معيار GLB، و`three_validation.json` لفحص التحميل والمحاور والمساعد. التحميل البرمجي في Node لا يعادل اختبار WebGL أو تشغيل السيارة في Motri2.

النتيجة النهائية: صفر أخطاء أو تحذيرات في فاحص glTF، وتحميل بنيوي ناجح عبر Three.js. اجتاز غلاف السيارة 532 عينة على المسار و712 وضعًا إجمالًا عند إضافة فحوص الدوران، دون تداخل مع مجسمات الموقع. لا توجد مثلثات عديمة المساحة أو مقاييس سالبة أو معدّلات نمذجة متروكة.
